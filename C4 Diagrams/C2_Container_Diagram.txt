================================================================================
                            DATA FLOW
================================================================================

1. PLAYER → Desktop Application (Pygame UI)
   ↓
2. Pygame UI → Simulation Engine [places orders, requests state]
   ↓
3. Simulation Engine → AI Policy System [gets AI orders]
   ↓
4. Simulation Engine → Persistence Layer [logs weekly data]
   ↓
5. Persistence Layer → File System [writes CSV/JSON]
   ↓
6. File System → Analysis Notebook [reads CSV for visualization]


================================================================================
                      CONTAINER INTERACTIONS
================================================================================

Desktop Application ←→ Simulation Engine
  • Sends: Player orders, configuration settings
  • Receives: Tier states, costs, inventory levels, game status

Simulation Engine → AI Policy System
  • Sends: Current tier state (inventory, backlog, incoming orders)
  • Receives: Calculated order quantities

Simulation Engine → Persistence Layer
  • Sends: Weekly metrics, game events
  • Receives: Saved game states (on load)

Persistence Layer → File System
  • Writes: game_state.json, game_log.csv, game.csv
  • Reads: Previous game states

Analysis Notebook ← File System
  • Reads: game_log.csv, game.csv for post-game analysis
